# AvatarManager

<div class="api-kind" v-pre><strong>Namespace.</strong> Can be used in: client scripts, entity scripts, avatar scripts.</div>

<div class="api-text" v-pre><p>The <code>AvatarManager</code> API provides information about avatars within the current world. The avatars available are those that Interface has displayed and therefore knows about.</p>
 <p><strong>Warning:</strong> This API is also provided to Interface, client entity, and avatar scripts as the synonym, "<code>AvatarList</code>". For assignment client scripts, see the separate <a href="AvatarList"><code>AvatarList</code></a> API.</p></div>

## Functions {#functions}

<div class="api-entry">

### findRayIntersection {#findRayIntersection}

```js
AvatarManager.findRayIntersection(ray, avatarsToInclude?, avatarsToDiscard?, pickAgainstMesh?)
```

<div class="api-text" v-pre><p>Find the first avatar intersected by a <a href="globals#PickRay"><code>PickRay</code></a>.</p></div>
<div class="api-table" v-pre><strong>Parameters</strong><table><thead><tr><th>Name</th><th>Type</th><th>Default</th><th>Description</th></tr></thead><tbody>
<tr><td><code>ray</code></td><td><a href="globals#PickRay">PickRay</a></td><td></td><td><p>The ray to use for finding avatars.</p></td></tr>
<tr><td><code>avatarsToInclude</code> <em>optional</em></td><td>Array&lt;<a href="Uuid">Uuid</a>&gt;</td><td><code>[]</code></td><td><p>If not empty then search is restricted to these avatars.</p></td></tr>
<tr><td><code>avatarsToDiscard</code> <em>optional</em></td><td>Array&lt;<a href="Uuid">Uuid</a>&gt;</td><td><code>[]</code></td><td><p>Avatars to ignore in the search.</p></td></tr>
<tr><td><code>pickAgainstMesh</code> <em>optional</em></td><td>boolean</td><td><code>true</code></td><td><p>If <code>true</code> then the exact intersection with the avatar mesh is calculated, if <code>false</code> then the intersection is approximate.</p></td></tr>
</tbody></table></div>
<div class="api-returns" v-pre><strong>Returns:</strong> <a href="globals#RayToAvatarIntersectionResult">RayToAvatarIntersectionResult</a> <p>The result of the search for the first intersected avatar.</p></div>

<div class="api-example" v-pre><strong>Example:</strong> <p>Find the first avatar directly in front of you.</p></div>

```js
var pickRay = {
    origin: MyAvatar.position,
    direction: Quat.getFront(MyAvatar.orientation)
};

var intersection = AvatarManager.findRayIntersection(pickRay);
if (intersection.intersects) {
    print("Avatar found: " + JSON.stringify(intersection));
} else {
    print("No avatar found.");
}
```

### getAvatarsInRange {#getAvatarsInRange}

```js
AvatarManager.getAvatarsInRange(position, range)
```

<div class="api-text" v-pre><p>Gets the IDs of all avatars known about within a specified distance from a point. Your own avatar's ID is included in the list if it is in range.</p></div>
<div class="api-table" v-pre><strong>Parameters</strong><table><thead><tr><th>Name</th><th>Type</th><th>Description</th></tr></thead><tbody>
<tr><td><code>position</code></td><td><a href="Vec3">Vec3</a></td><td><p>The point about which the search is performed.</p></td></tr>
<tr><td><code>range</code></td><td>number</td><td><p>The search radius.</p></td></tr>
</tbody></table></div>
<div class="api-returns" v-pre><strong>Returns:</strong> Array&lt;<a href="Uuid">Uuid</a>&gt; <p>The IDs of all known avatars within the search distance from the position.</p></div>

<div class="api-example" v-pre><strong>Example:</strong> <p>Report the IDs of all avatars within 10m of your avatar.</p></div>

```js
var RANGE = 10;
var avatars = AvatarManager.getAvatarsInRange(MyAvatar.position, RANGE);
print("Nearby avatars: " + JSON.stringify(avatars));
print("Own avatar: " + MyAvatar.sessionUUID);
```

### getPalData {#getPalData}

```js
AvatarManager.getPalData(avatarIDs?)
```

<div class="api-text" v-pre><p>Gets PAL (People Access List) data for one or more avatars. Using this method is faster than iterating over each avatar and obtaining data about each individually.</p></div>
<div class="api-table" v-pre><strong>Parameters</strong><table><thead><tr><th>Name</th><th>Type</th><th>Default</th><th>Description</th></tr></thead><tbody>
<tr><td><code>avatarIDs</code> <em>optional</em></td><td>Array&lt;string&gt;</td><td><code>[]</code></td><td><p>The IDs of the avatars to get the PAL data for. If empty, then PAL data is obtained for all avatars.</p></td></tr>
</tbody></table></div>
<div class="api-returns" v-pre><strong>Returns:</strong> Object&lt;&quot;data&quot;, Array&lt;<a href="#PalData">AvatarManager.PalData</a>&gt;&gt; <p>An array of objects, each object being the PAL data for an avatar.</p></div>

<div class="api-example" v-pre><strong>Example:</strong> <p>Report the PAL data for an avatar nearby.</p></div>

