# Paths

<div class="api-kind" v-pre><strong>Namespace.</strong> Can be used in: client scripts, entity scripts, avatar scripts.</div>

<div class="api-text" v-pre><p>The <code>Paths</code> API provides absolute paths to the scripts and resources directories.</p></div>

## Properties {#properties}

<div class="api-table" v-pre><table><thead><tr><th>Name</th><th>Type</th><th>Description</th></tr></thead><tbody>
<tr><td><code>defaultScripts</code></td><td>string</td><td><p>The path to the scripts directory. <em>Read-only.</em></p></td></tr>
<tr><td><code>resources</code></td><td>string</td><td><p>The path to the resources directory. <em>Read-only.</em></p></td></tr>
</tbody></table></div>
