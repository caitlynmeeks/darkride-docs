# What's new in 1.1.3.1

Darkride 1.1.3.1 beta is on [GitHub](https://github.com/caitlynmeeks/darkride-interface/releases/latest). For what
changed in 1.1.3, see [What's new in 1.1.3](/releases/1.1.3/); for what doesn't work yet, see
[Known issues](/known-issues).

**1.1.3.1 is a small safety update.** It improves how Darkride handles some model files, compressed downloads and
other visitors' avatars. Nothing else changes. Please update, and download Darkride only from
[darkride.ai/download](https://darkride.ai/download) or its
[GitHub release page](https://github.com/caitlynmeeks/darkride-interface/releases/latest).

If you host your own world, update your server too: the server download carries the same fixes. To update it, follow
[Update to a new version](/worlds/your-own-server#update-to-a-new-version).
